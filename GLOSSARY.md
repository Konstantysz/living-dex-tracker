# Glossary

Domain terms of the Living Dex tracker. The documentation is in English. The UI is in Polish, so
each term also has its Polish UI name. Use these terms in code, issues and docs. Do not use the
"Avoid" synonyms.

The "Code" column names the identifier that holds the concept. An identifier that does not match
the term is marked _(rename)_: align it with the term when you next change that code.

Terms marked _(planned)_ name features that are not built yet.

In-game names (places, shrines, Pokémon) exist only in English. The UI shows them in English.

| Term (EN)                  | UI name (PL)     | Code                                                              | Meaning                                                                                                                                              | Avoid                               |
| -------------------------- | ---------------- | ----------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------- |
| Entry                      | Wpis             | `DexEntry`, `DexEntry.id`                                         | One slot to fill: the base form or another form of a species. Its `id` is the key in the caught set and in the backup code.                          | slot (for the data), pokemon        |
| Form                       | Forma            | `DexEntry.form`, `DexEntry.k`                                     | One entry that is not the base form, e.g. Rotom-Heat or a female. `k` is its kind.                                                                   | variant                             |
| Species                    | Gatunek          | `SpeciesGroup`, `SpeciesGroup.sp`, `GameLayout.groups` _(rename)_ | All entries of one species. `mergedLines` joins a few species into one (Scatterbug to Vivillon, Flabébé to Florges). The unit of box packing.        | group                               |
| Evolution line             | Linia ewolucyjna | —                                                                 | The species with the same `evolution_chain_id` in `pokemon_species.csv`, e.g. Sprigatito, Floragato, Meowscarada.                                    | family, chain                       |
| Caught set                 | Złapane          | `caught`, `loadCaught`, `saveCaught`                              | The set of ids the player marked: entry ids and collectible ids. Stored per game in localStorage.                                                    | progress, save                      |
| Collectible                | Znajdźka         | `CollectibleSet`, `collectibleId`, `isEntryId`                    | An in-game object the player collects outside the dex, tracked as a checklist in the Guide. A set has sections. Id `<set>:<section>-<n>` (ADR 0002). | item, pickup, group (for a section) |
| Dex                        | Pokédex          | `DexConfig`, `GameConfig.dexes`                                   | A regional dex of the game (Paldea, Kitakami, Blueberry; Lumiose and Hyperspace in Z-A).                                                             | region                              |
| Version exclusive          | Ekskluzyw        | `GameConfig.exclusives`, `DexEntry.v`                             | A species that one version of the game (e.g. Scarlet) has and the other does not.                                                                    | exclusive pokemon                   |
| Badge                      | Odznaka          | `Badge`, `gameBadges`, `Badge.isHidden`                           | An award computed from the caught set, like a trophy or an achievement: title, info, image, `is_hidden`. Never stored.                               | achievement, trophy                 |
| Badge collection           | Kolekcja         | `Badge.item`                                                      | Badges with the same title, one per item, e.g. "Pełny box" with one badge per box.                                                                   | badge group                         |
| Ruin stake                 | Słupek ruin      | collectible set `stake`                                           | The SV collectible: 32 stakes, 8 per shrine, that unlock a Treasure of Ruin. Id `stake:<shrine>-<n>`.                                                | kołek, wedge                        |
| Shrine                     | Świątynia        | `CollectibleSet.sections` of `stake`                              | One of the 4 Treasures of Ruin shrines. Opens when its 8 stakes are pulled.                                                                          | ruin, temple                        |
| Area _(planned)_           | Obszar           | —                                                                 | A named place on the game map. Its key is the slug from the Serebii Pokéarth URL (e.g. `eastprovinceareaone`).                                       | zone, location                      |
| Location _(planned)_       | Miejsce złapania | —                                                                 | Where an entry can be obtained in one version: areas, fixed encounters, Tera Raid stars. Data from Serebii.                                          | spawn, habitat                      |
| Tip _(planned)_            | Porada           | —                                                                 | A hint computed from the caught set and locations, e.g. "evolve X you have", "breed X".                                                              | guide (for one hint)                |
| Guide                      | Poradnik         | `GuideDialog`                                                     | The dialog with all help for obtaining entries. Now: collectibles and badges. Later: locations, tips, the map.                                       | walkthrough                         |
| Details dialog _(planned)_ | Szczegóły        | —                                                                 | The dialog of one entry. Desktop: "i" button on hover or right click. Phone: details mode in the header, long press as an extra.                     | modal, popup                        |
| Area map _(planned)_       | Mapa             | —                                                                 | The interactive game map. Areas are SVG path data with `id` = area slug.                                                                             | world map                           |
